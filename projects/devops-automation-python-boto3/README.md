# DevOps Automation Toolkit

Python and Boto3 automation reference project for AWS operations.

## Planned capabilities

- EC2 inventory and health checks
- EBS and S3 operational reporting
- CloudWatch metric queries
- Tag compliance checks
- Resource discovery
- Safe operational reporting

## Engineering principles

- Least-privilege IAM
- Dry-run support where appropriate
- Structured logging
- Error handling and retries
- No hard-coded credentials
- Environment-based configuration

This project reflects the Python/Boto3 automation experience in the professional profile.
