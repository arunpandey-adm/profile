# AWS 3-Tier Architecture with Terraform

Production-oriented reference architecture demonstrating a secure AWS 3-tier pattern.

## Architecture

`Route53 → Load Balancer → Application Tier → RDS`

Supporting services: VPC, public/private subnets, IAM, CloudWatch, security groups and S3.

## Skills demonstrated

- AWS VPC and subnet design
- High availability with multiple Availability Zones
- Application Load Balancer
- EC2 / Auto Scaling architecture
- RDS integration
- IAM and security groups
- Terraform Infrastructure as Code
- CloudWatch observability

> This repository is a portfolio reference implementation. No production credentials or customer infrastructure are included.
