# CI/CD with Jenkins + Terraform

Enterprise-style CI/CD reference project for infrastructure and application delivery.

## Pipeline flow

`Git → Jenkins → Validate → Terraform Plan → Approval → Terraform Apply → Deploy → Smoke Test`

## Skills demonstrated

- Jenkins pipeline design
- Terraform plan/apply workflow
- Automated validation
- Deployment gates and approvals
- Build and deployment troubleshooting
- Cloud deployment automation

The design reflects the CI/CD and IaC responsibilities described in the professional profile without exposing client-specific pipelines or configuration.
