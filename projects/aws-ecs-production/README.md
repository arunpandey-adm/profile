# AWS ECS Production Setup

Reference architecture for deploying containerized workloads on AWS ECS.

## Components

- ECS service and task definitions
- ECR container registry
- Application Load Balancer
- VPC and security groups
- Auto Scaling
- CloudWatch logging and monitoring
- IAM task and execution roles
- Terraform for repeatable provisioning

## Goal

Demonstrate how to design a scalable, secure and observable container platform suitable for enterprise workloads.
