# AWS Observability Platform

Reference observability design using CloudWatch, Prometheus, Grafana and Splunk patterns.

## Capabilities

- Infrastructure and application metrics
- Dashboard design
- Alerting and notification patterns
- CI/CD pipeline monitoring
- Production health checks
- Incident investigation workflow

## Architecture concept

`AWS Workloads → Metrics/Logs → CloudWatch/Prometheus → Grafana/Splunk → Alerts → Incident Response`

The project is designed to demonstrate practical enterprise observability skills without publishing customer data.
