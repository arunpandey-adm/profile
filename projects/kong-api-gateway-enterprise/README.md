# Enterprise Kong API Gateway

Reference portfolio project based on Arun's enterprise Kong API Gateway experience.

## Focus areas

- Kong API Gateway for microservices
- Authentication and authorization patterns
- OIDC / OAuth2 concepts
- Custom Kong plugins
- API traffic management
- Gateway observability with Prometheus and Grafana
- Migration strategy from legacy API gateways

## Outcomes represented by the portfolio

- Experience operating Kong across 50+ microservices
- API response improvement through gateway modernization
- Infrastructure automation with Terraform

> Portfolio implementation only. No customer APIs, credentials or proprietary configuration are included.
